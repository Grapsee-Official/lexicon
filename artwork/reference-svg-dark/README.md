# Interior night reference artwork

The 32 night variants in this directory preserve the actual vector path geometry traced from the supplied light screen references. They use the supplied night palette as a design direction: ink shadow, night-sky blue, muted botanical foliage and warm brass stone and wood pigments. Low-opacity parchment washes are reduced toward the midnight field instead of using a rectangular tinted background.

These are inferred night treatments, not separate approved dark interior mockups. The original light reference SVGs, original dark illustrations and independently supplied dark Home artwork remain unchanged. Each scene has a matching Android VectorDrawable and iOS asset catalog entry. The UI selects the appearance-specific asset, falls back to the original illustration if a scene has no reference variant, and uses the same bounded renderer cache for both vector appearances.

No screenshot is used as a screen background. Labels, word data, navigation, buttons, cards, filters, notes and progress remain native interactive UI.
