# Lexora heritage navigation icon set

Five original, deliberately restrained 24×24 vector marks for Home (English cottage), Dictionary (open folio), Search (brass magnifier with glint), Collections (botanical bookmark), and More (four-pane leaded heritage window).

## Masters and implementations

- Master SVGs: `public/icons/heritage/{home,dictionary,search,collections,more}.svg` (black opaque strokes on transparent canvas, 24×24; CSS masks recolor by theme).
- Android: matching `res/drawable/heritage_nav_*.xml` VectorDrawables rendered by `painterResource` and tinted with existing theme colors.
- iOS: matching, resolution-independent SwiftUI `Path` geometry rendered in `BottomNav.swift`, tinted with existing theme colors.
- Web: use the SVG master as a CSS mask in `bottom-nav.tsx`, retaining existing sizes and active-state colors.

The More motif deliberately replaces an ellipsis with a four-pane, pointed-arch English cottage window: four panes reflect the four settings groups (Appearance, Dictionary, Privacy & Data, About). Retain its explicit **More** label, because decorative metaphors can be ambiguous without text.

## Contract

Do not change navigation order, text labels, search action, touch targets, active-state dot, semantics, theme colors, or capsule layout. All icons remain transparent with subtle engraving instead of miniature photorealistic illustrations; detail must remain legible at 19 pt/dp. The center magnifier renders at 20px Web / 24dp Android / 24pt iOS within the existing circle. Dark gold and light forest-green variants are generated by tint, not duplicated bitmaps.

## QA checklist

- Verify icon silhouettes and alignment on iOS, Android and Web in both themes.
- Verify screen-reader labels and selected-state announcements; ensure each target remains comfortably tappable.
- Check 320–360dp compact widths and larger accessibility text settings.
- Confirm Web SVG mask compatibility with target browsers and inspect real-device screenshots before production approval.

No changes to navigation behavior or category illustration assets are intended.
